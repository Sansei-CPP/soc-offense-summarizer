# Threat Intel: Tor Exit Nodes

## Описание

Tor exit nodes — последнее звено в сети анонимизации Tor.
Трафик с Tor exit nodes не поддаётся атрибуции реального источника.
Атакующие часто используют Tor для брутфорса, credential stuffing
и разведки, скрывая своё происхождение.

## Ключевые индикаторы

- Reverse DNS часто разрешается в tor-exit, exit-node или relay hostnames.
- Присутствует в публичных блок-листах: dan.me.uk/torlist,
  check.torproject.org.
- IP-диапазоны ассоциированы с известными Tor-хостинг провайдерами.

## Рекомендованные действия

- Любой брутфорс с подтверждённого Tor exit node следует рассматривать
  с повышенной подозрительностью вне зависимости от исхода.
- Если аутентификация прошла успешно с Tor exit node —
  немедленно эскалировать и инициировать ревью аккаунта.
- Не закрывать автоматически как FP без подтверждения от клиента.
