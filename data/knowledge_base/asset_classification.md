# Классификация активов

## Критические активы (всегда эскалировать при компрометации)

- Серверы аутентификации (LDAP, AD, RADIUS, SSO)
- Production базы данных
- Domain controllers
- Jump hosts / bastion серверы
- CI/CD системы

## Активы высокой ценности (эскалировать при прямой атаке)

- Файловые серверы
- Почтовые серверы
- Внутренние API-шлюзы

## Стандартные активы

- Рабочие станции разработчиков
- Внутренние веб-серверы (non-production)
- Мониторинговая инфраструктура

## Замечание по именованию

Имена хостов, содержащие auth, dc, ldap, sso, prod, bastion,
следует считать критическими, если клиент не подтвердил иное.
